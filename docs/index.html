PHC Neural Control / Unreal Engine 5.8

Neural Network–Driven Character Animation

PHC neural networks control 100 characters as they react to falling rocks, lose balance, and attempt to run again in physics simulation. The resulting skeletal animation is presented in Unreal Engine.

How neural control drives the skeleton

Pretrained PHC neural networks read each character’s state and reference motion at every control step and output joint-control actions. PD controllers and PhysX resolve body motion, ground support, and collisions. Characters share policy weights and retain independent simulation states.

Neural inference → joint control → physics simulation → skeletal retargeting → Unreal animation

Unreal plays the baked output of offline neural control and physics simulation. Code aligns recovered characters with the reference run cycle. A scene-defined terminal rule holds a down pose. This project uses existing pretrained PHC weights.

Three drop sizes in a dense crowd

Sixteen runners share the same compact formation. At one density, the 12, 45 and 100 cm spheres weigh about 0.9, 47.7 and 523.6 kg. The lightest ball clips one runner without knocking them down.

Flash pulse and stylized dart

Two visual cues share the same recorded point-force trial, so the character reactions can be compared on the same timeline.

Run the Unreal project

Run the setup script to import Manny from your local Epic Content Examples and bake the recorded trials. Then open BoulderCrowd.uproject in Unreal Engine 5.8 and open L_Drop_100 and press Play.
