Physics-Guided Character Animation

Four mannequins start with the same run. A 250 N force pulse at the lower leg, shoulder, or chest produces three different reactions alongside an unperturbed control.

Lower leg
Keeps running
Shoulder
Falls, stands up, resumes running
Chest
Stays motionless after settling
Control
Runs without a force pulse

Getting back to a run

Watch the shoulder lane in both views. The original PHC trial ends in slow steps. The revised playback matches the stance to the run cycle and blends towards the original speed over 32 frames.

Three drop sizes in a dense crowd

Sixteen runners share the same compact formation. At one density, the 12, 45 and 100 cm spheres weigh about 0.9, 47.7 and 523.6 kg. The lightest ball clips one runner without knocking them down.

100 runners in one simulation

A 10 × 10 group, a 1 m sphere, and eight seconds of PhysX / PHC motion. Four runners complete the return to running within the clip. Nine reach the terminal game state and stay motionless.

Eight runners and a boulder

Glancing contacts blend back into the run over 32 frames. Runners that reach the terminal game state stay motionless after settling.

Flash pulse and stylized dart

Two visual cues share the same recorded point-force trial, so the character reactions can be compared on the same timeline.

Run the Unreal project

Run the setup script to import Manny from your local Epic Content Examples and bake the recorded trials. Then open BoulderCrowd.uproject in Unreal Engine 5.8 and press Play in the default 250 N map.
