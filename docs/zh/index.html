物理引导角色动画

四个角色从同一个跑步动作起步。同样的 250 N 短时外力分别作用在小腿、肩侧和胸口，产生三种反应。第四个角色提供无外力对照。

小腿
继续跑动
肩侧
跌倒、站起、继续奔跑
胸口
试次结束时仍然倒地
对照
未施加外力，继续奔跑

起身后怎么接回跑步

同时看两边的肩侧组。原始 PHC 片段以慢步结束。改进版按双脚支撑姿态对齐跑步相位，并在 32 帧内逐渐恢复原跑速。

一个滚石，八名跑者

群演场景采用同样的离线流程。轻擦的角色回到跑步循环，受到严重撞击的角色保持倒地。

打开 Unreal 工程

先运行安装脚本，从本机 Epic Content Examples 导入 Manny，再把仓库里的试次记录烘焙成关卡和动画。用 Unreal Engine 5.8 打开 BoulderCrowd.uproject，在默认的 250 N 关卡点 Play。
