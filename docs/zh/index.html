PHC Neural Control / Unreal Engine 5.8

神经网络驱动的角色动画

PHC 神经网络控制 100 个角色，在物理仿真中应对落石、跌倒并尝试恢复奔跑，再将计算出的骨骼动画呈现在 Unreal Engine。

神经网络如何驱动骨骼

预训练的 PHC 神经网络每步读取角色状态与参考运动，输出关节控制动作。PD 控制器和 PhysX 共同求解身体运动、地面支撑与角色间碰撞。角色共享策略权重，各自拥有独立的仿真状态。

神经网络推理 → 关节控制 → 物理仿真 → 骨骼运动重定向 → Unreal 动画

Unreal 当前播放离线烘焙的神经网络与物理仿真结果。起身后的跑步相位匹配由代码完成，死亡采用场景规则，达到终止条件后保持倒地。本项目使用现有 PHC 预训练权重。

三种尺寸的落石，16 人密集队列

球体密度相同。直径 12、45、100 厘米时，质量分别约为 0.9、47.7、523.6 千克。最小的球擦到一名跑者，对方没有倒下。

闪光脉冲与箭形道具

两种视觉效果共用同一组点力试次，在同一条时间轴上对比角色反应。

打开 Unreal 工程

先运行安装脚本，从本机 Epic Content Examples 导入 Manny，再把仓库里的试次记录烘焙成关卡和动画。用 Unreal Engine 5.8 打开 BoulderCrowd.uproject，打开 100 人关卡 L_Drop_100 并点 Play。
