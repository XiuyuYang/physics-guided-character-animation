# Credits and third-party materials

- **Perpetual Humanoid Control (PHC)** by Zhengyi Luo and collaborators powers the offline trials. See the [upstream project and its terms](https://github.com/ZhengyiLuo/PHC).
- **NVIDIA Isaac Gym** runs the PhysX simulation used for the recorded trials. The simulator, upstream model weights, and motion-reference source files are obtained separately.
- **Unreal Engine**, the Manny mannequin, and the original `MM_Run_Fwd` animation are from Epic Games. The setup script imports the mannequin assets from a local [Content Examples](https://dev.epicgames.com/documentation/unreal-engine/content-examples-sample-project-for-unreal-engine?lang=en-US) project. Epic's asset files stay in the local project. See the [Unreal Engine terms](https://www.unrealengine.com/eula/unreal) and [Epic Content terms](https://www.unrealengine.com/eula/content).
- This repository includes recorded simulation outputs, project scripts, and rendered Unreal clips.
